# Tote

何でも放り込んで持ち運ぶ、自作のWinRAR代替アーカイバ。v0.1.0 は「ZIP作成」だけ。

## ビルド (Windows)
    cargo build --release
    → target\release\tote.exe（アイコン入り。rc.exe が無い環境ではアイコン無しで警告のみ）

## 使い方
1. `tote.exe` をダブルクリック → 「はい」で右クリックメニューと「送る」に登録（HKCU/ユーザーフォルダのみ、管理者権限不要）
2. 右クリック → (Win11は「その他のオプションを確認」) → ToteでZIPに圧縮
3. 15個超を選ぶときは 右クリック → 送る → ToteでZIPに圧縮。D&Dも可
4. 解除は `tote.exe --uninstall`（exeを移動したら再登録）。旧名 zipr の登録が残っていれば登録/解除時に一緒に消える

## 仕様
- フォルダ1つだけ選択 → 中身をZIPルート直下へ（二重フォルダ無し）
- 複数選択/ファイル → 各項目をルート直下へ
- 出力は入力と同じ場所。既存は上書きせず `name (1).zip`
- 3秒以上かかった場合のみ、完了後にエクスプローラーでZIPを選択表示

## 構成
- core/  ZIP作成ロジック（v0.2のビューア・展開・追記もここに足す）
- app/   exe（引数処理、複数選択の集約、レジストリ/送る登録）
- app/assets/  アイコン（tote.ico）
